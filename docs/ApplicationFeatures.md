# Application Features

## Public Catalog

- Browse categories.
- Browse products.
- View product details.
- View product availability.
- View product image galleries.

## Authentication

- Register a customer account.
- Log in.
- Log out.
- Get current user information.
- Use Customer and Admin roles.

## Cart

- Use a local cart as a Guest.
- Use a server cart as an authenticated Customer.
- Add products to cart.
- Increase and decrease product quantity.
- Remove products from cart.
- Synchronize the local cart with the server cart after login.

## Orders

- Create an order from the server cart.
- Validate stock during order creation.
- View customer order history.
- View order details.
- Edit delivery information for eligible orders.
- Cancel eligible orders.

## Administration

### Categories

- Create category.
- Edit category.
- Delete category.

### Products

- Create product.
- Edit product.
- Delete product.
- Add product images.
- Remove product images.

### Orders

- Find an order by ID.
- View order details.
- Change order status according to the allowed transitions.
