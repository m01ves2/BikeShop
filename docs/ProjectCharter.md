# BikeShop

## Vision

BikeShop is a simple online bicycle store that allows customers to browse products and place orders through a clean and user-friendly web application.


## Goals
- Provide a complete online shopping workflow.
- Demonstrate clean layered architecture.
- Implement secure user authentication.
- Deliver a simple and consistent user interface.


## Scope
### In Scope
- Catalog
- Cart
- Orders
- Product card
- User authentication and authorization

### Out of Scope
- Coupons/Sales
- Ratings and reviews
- Payment integration
- Recommendation system
- Notifications
- Subscription

## Technology Stack
- ASP.NET Core
- EF
- Blazor Server
- SQL Server
- Bootstrap

## Constraints
- Single-vendor online store.
- Small-scale educational project.
- Layered architecture.
- Two-week implementation.
- Bootstrap-based UI.

## Success Criteria

- User can register.
- User can browse product's catalogue.
- User can add products to cart.
- User can create an order.
- Application runs without critical errors.
- All MVP features are implemented and functional.
