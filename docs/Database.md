# Database Design

## 1. Overview
The BikeShop application uses a relational database to persist business data.
The database schema is designed to reflect the domain model while supporting efficient querying, data integrity, and future extensibility.
Relationships between entities are enforced using foreign keys and appropriate constraints.

## 2. Main Tables

### 2.1 Products

Purpose:
Stores information about products available in the catalog.

Main fields:

- Id
- Name
- Description
- Price
- StockQuantity
- CategoryId


### 2.2 Categories
Purpose:
Stores product categories.

Fields:
- Id
- Name


### 2.3 Customers
Purpose:
Stores customer business information.

Fields:

- Id
- FirstName
- LastName
- Phone
- Email


### 2.4 Cart
Purpose:
Represents customer's shopping cart.

Implementation details are subject to further refinement.

### 2.4 CartItem
Purpose:
Represents customer's shopping cart item.

Implementation details are subject to further refinement.

### 2.6 Orders
Purpose:

Fields:
- Id
- CustomerId
- CreatedAt
- Status
- TotalPrice



### 2.7 OrderItems
Purpose:

Fields:
- Id
- OrderId
- ProductId
- ProductPrice
- Quantity

Note:
ProductPrice stores the price at the moment of purchase.

Customer ||--o{ CartItem : has

## 4. Primary Keys
- All tables use a single-column primary key named Id.
- Primary keys are implemented as integer identity values generated by the database.

## 5. Foreign Keys
Products.CategoryId → Categories.Id

Cart.CustomerId → Customers.Id

CartItems.CartId → Carts.Id
CartItems.ProductId → Products.Id

Orders.CustomerId → Customers.Id

OrderItems.OrderId → Orders.Id
OrderItems.ProductId → Products.Id

## 6. Constraints
- Product belongs to exactly one Category.
- Customer owns one Shopping Cart.
- Order contains one or more OrderItems.
- ProductPrice cannot be negative.
- Quantity must be greater than zero.

## 7. Notes
- Authentication data is stored separately using ASP.NET Core Identity.
- The schema is intentionally normalized.
- Future versions may include discount tables, payment information, inventory history, and shipment tracking.
